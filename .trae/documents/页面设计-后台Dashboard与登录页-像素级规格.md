# 页面设计说明（Desktop 优先）
> 说明：当前仅基于会话中已收到的 1 张 Dashboard 截图整理；其余 4 张页面待你补图后我会按同规格补齐。

## 全局样式（两页共用）
- 画布与栅格：桌面端基准宽 1440；内容区左右 padding 24；主内容使用 12 栏栅格，列间距 24。
- 颜色（建议与截图对齐微调）：
  - 页面底色：#F4F6F8
  - 卡片底色：#FFFFFF
  - 分割线/边框：#E5E7EB
  - 主色（链接/高亮）：#2065D1
  - 成功/上涨：#16A34A；危险/下降：#DC2626；次级文字：#6B7280；主文字：#111827
- 字体层级：
  - Page Title：24/32，700
  - Section Title：16/24，600
  - Body：14/22，400
  - Caption：12/18，400
- 卡片通用：圆角 12；阴影 very subtle（或 1px 边框）；内边距 16~24（以截图为准）。
- 交互：侧边栏 item hover 背景浅灰；当前路由高亮（主色条/浅底）。

## 1) 登录页（/login）
### Layout
- 居中单列布局：页面底色沿用全局；表单卡片固定宽 420（<= 480）；上下居中（最小上边距 120）。

### Meta Information
- title: 登录 - 管理后台
- description: 管理后台登录
- og:title/og:description 同上

### Page Structure
1. Logo/产品名（居中，距卡片上方 24）
2. 登录卡片（白底圆角 12，padding 24，卡片间距 16）

### Sections & Components
- 标题区：
  - H1："Sign in"/"登录"（按产品语言），下方辅助文案（Caption，灰色）
- 表单区：
  - 账号输入框：label（12px）+ input（高度 44，左右 padding 12）
  - 密码输入框：同上；右侧可选“显示/隐藏”图标（20px）
  - 错误提示：字段下方 12px 文案，红色；顶部可选全局错误条
  - 提交按钮：高度 44，圆角 8~10，主色实心；loading 状态禁用
- 额外："忘记密码"若截图无则不做；仅保留必需登录。

## 2) 后台概览页 Dashboard（/admin/dashboard）
### Layout
- 整体：Left Sidebar + Top AppBar + Main Content。
- Sidebar：固定宽 280（允许 260~300 微调），全高；内容垂直列表。
- AppBar：高度 64；左侧面包屑/标题；右侧用户区（头像 32、下拉）。
- Main：背景 #F4F6F8；内容区 padding 24。

### Meta Information
- title: Dashboard - 管理后台
- description: 管理后台概览与核心指标
- og:title/og:description 同上

### Page Structure（按截图从上到下）
1. 页面标题行："Dashboard" 左对齐；右侧可放日期/筛选（若截图存在）。
2. KPI 卡片行（4 张）：12 栏下每张占 3 栏；卡片间距 24。
3. 图表与侧卡区域：左侧趋势图（占 8~9 栏），右侧来源分布/排行（占 3~4 栏）。
4. 底部列表：最新订单表格卡片（12 栏全宽）。

### Sections & Components（像素级要点）
#### A. Left Sidebar
- 顶部品牌区：高度 72；左 padding 24；Logo 28 + 文本 16/600。
- 导航列表：
  - item 高度 44~48；左右 padding 16~20；icon 20；icon 与文案间距 12。
  - active：左侧 3px 主色条（或整行浅主色底）；文案 14/600。

#### B. Top AppBar
- 左：页面标题/面包屑（16/600）。
- 右：
  - 通知/设置图标按钮（若有）：32x32 hit area；icon 20。
  - 用户头像：32 圆形；名称（14/600）与下拉箭头间距 8。

#### C. KPI Cards（4 张）
- 卡片：白底、圆角 12、padding 16~20。
- 内容：
  - 顶部：标题（Caption 灰）+ 右侧趋势/图标（若截图有）。
  - 主数值：28~32px、700。
  - 底部：环比/同比（12px）：上升绿色 + 箭头；下降红色。

#### D. 趋势图卡片（折线/面积）
- 标题行：左侧 Section Title；右侧范围选择（7d/30d/90d 或日期，若截图有）。
- 图表区域：高度 320~360；x 轴日期；y 轴数值；网格线浅灰。
- tooltip：白底阴影；点位 hover 放大 4->6。

#### E. 来源分布卡片（饼/环图）
- 图表：居中；环宽 12~16；中心可放总计。
- 图例：右侧或下方（按截图），每行：色块 10 + 名称 12/18 + 数值/占比。

#### F. 最新订单表格卡片
- 表头：12/600，灰；行高 48；单元格左右 padding 16。
- 列（以截图为准）：订单号/客户/日期/金额/状态。
- 状态：tag 胶囊（高度 24，padding 8~10，圆角 999），不同状态不同底色。
- 空态：居中 icon + 文案；加载：骨架屏 3~5 行。
