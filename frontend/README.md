# 学生综合服务平台管理后台

本目录为学院学生综合服务与党团管理平台的 Vue 3 管理后台，包含学生信息、通知、知识库、审批、导入任务和平台设置等管理页面。

完整的项目定位、后端启动方式和系统边界见仓库根目录的 [README](../README.md)。

## 技术栈

- Vue 3
- Vue Router
- Pinia
- Element Plus
- Axios

## 本地运行

```bash
npm install
npm run serve
```

接口地址等本地配置参考 [`.env.example`](.env.example)。

## 构建与检查

```bash
npm run build
npm run lint
```
